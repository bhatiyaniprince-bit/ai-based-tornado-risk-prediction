# ai-based-tornado-risk-prediction
College project for AI -Based Tornado Risk Prediction and Early Warning System Using Weather and Wind Data
AI-Based Tornado Risk Prediction System

About the Project

An educational Python project that demonstrates a basic machine-learning workflow and a Streamlit web interface for exploring weather data.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
- Google Colab

Project Files

- "tornado risk prediction.ipynb" — project notebook
- "app.py" — Streamlit application
- "demo_model.joblib" — saved demonstration model
- "requirements.txt" — required Python libraries

Current Status

Educational prototype under development. The current model uses simulated data and arbitrary demonstration labels.

Important Safety Notice

This project is not a validated tornado forecasting or early-warning system. Its predictions must not be used for real-world safety decisions. Reliable warnings should come from official meteorological authorities.

Run Locally

Install the dependencies:

"pip install -r requirements.txt"

Then run:

"streamlit run app.py"

Ensure "demo_model.joblib" is in the same directory as "app.py".
